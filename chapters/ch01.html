Chapter 1 · Lectures 1–4

Matrices, vector spaces, and linear maps

L1 L2 L3 L4

A calibration device combines two settings and reports two signals. Changing the units or using different combinations as coordinates changes the matrix in the calibration file. It should leave the device's predictions intact. To check that, we need to tell apart the device's rule, the vectors it acts on, and the coordinates used to write each vector.

Use an original dimensionless model throughout. If \(u\) and \(v\) are actuator settings, the measured sum is \(u+v\) and a weighted contrast is \(u-v\). The model is idealized: real gain offsets or saturation need extra terms.

Matrix multiplication composes operations (L1 16:09)

Write \(\mathbb F\) for either the real field \(\mathbb R\) or the complex field \(\mathbb C\). An \(m\)-by-\(n\) matrix \(A\) over \(\mathbb F\) is an array with entries \(a_{ij}\in\mathbb F\) indexed by row \(i\) and column \(j\). We represent a member \(x\) of \(\mathbb F^n\) as a column. Define its image \(Ax\in\mathbb F^m\) by the rule \((Ax)_i=\sum_{j=1}^n a_{ij}x_j\). Each row specifies a linear measurement. Each column gives the output for the corresponding coordinate input. In the device model,

\[A=\begin{pmatrix}1&1\\1&-1\end{pmatrix},\qquad x=\begin{pmatrix}u\\v\end{pmatrix},\qquad Ax=\begin{pmatrix}u+v\\u-v\end{pmatrix}.\]

Suppose another matrix \(B\) maps the pair of signals to \(p\) reported numbers. If \(B\) has shape \(p\)-by-\(m\), the \(i\)th component of the composite \(B(Ax)\) is

\[\sum_{k=1}^m b_{ik}\sum_{j=1}^n a_{kj}x_j =\sum_{j=1}^n\left(\sum_{k=1}^m b_{ik}a_{kj}\right)x_j.\]

The inner sum is the entry \((BA)_{ij}\). Its shared index \(k\) represents an intermediate channel. The same calculation proves associativity for compatible shapes: either order of grouping in three successive maps contracts over the same two intermediate indices. The identity matrix \(I_n\), with ones on the diagonal and zeros elsewhere, implements the operation \(I_nx=x\).

Composition order can affect the output even when both products exist. Take \(B=\operatorname{diag}(2,1)\), which doubles just the first component. For \(x=(3,1)^T\), where \(T\) denotes transpose, \(BAx=(8,2)^T\) and \(ABx=(7,5)^T\). The former doubles the sum after the device responds. The latter doubles an actuator input before measurement.

For a square matrix \(M\) of order \(n\), its trace is \(\operatorname{tr}M=\sum_{i=1}^n m_{ii}\). Even when \(A\) and \(B\) are rectangular with complementary shapes, \(\operatorname{tr}(BA)=\operatorname{tr}(AB)\) since both traces sum \(b_{ik}a_{ki}\) over all pairs of indices. The example gives trace \(1\) for both products. Cyclic equality of traces thus records a scalar invariant while losing information about the product entries.

The transpose \(M^T\) interchanges row and column indices. The adjoint \(M^*\) also conjugates each entry. A square matrix with \(M^*=M\) is Hermitian, and over \(\mathbb R\) the same condition says that \(M\) is symmetric. The device matrix \(A\) is real symmetric. The complex matrix \(H=\begin{pmatrix}0&i\\-i&0\end{pmatrix}\), where \(i^2=-1\), is Hermitian because exchanging its off-diagonal entries and conjugating them leaves them unchanged. The distinction will matter when we quantify lengths and prove spectral properties.

Vector spaces encode allowable combinations (L2 00:43)

A vector space over \(\mathbb F\) supports addition and scalar multiplication. Addition is commutative and associative, has a zero vector, and gives each vector an additive inverse. Multiplication by scalars respects multiplication in the field and leaves vectors unchanged under the scalar \(1\). It distributes both over vector addition and over scalar addition. These axioms make expressions such as \(\alpha x+\beta y\) unambiguous for vectors \(x,y\) and scalars \(\alpha,\beta\). Coordinate vectors use componentwise operations, but matrices of a fixed shape and polynomials of bounded degree also form vector spaces with their usual operations.

A subspace is a subset containing zero and closed under linear combinations using the ambient operations. Limit the device to balanced commands \(u+v=0\). Its set \(S=\{(t,-t)^T:t\in\mathbb F\}\) is a subspace because combining commands with parameters \(t_1,t_2\) gives the command with parameter \(\alpha t_1+\beta t_2\). Every balanced command produces zero sum and contrast \(2t\). If instead the sum is held at \(1\), the set contains \((1,0)^T\) but lacks the zero command. It is a translate of \(S\) by \((1,0)^T\). An affine constraint of this kind is converted to a subspace constraint by subtracting a feasible reference command.

The span of a list consists of all finite linear combinations of list members. This is a subspace since combinations of combinations are still combinations of the original list. Any subspace that contains the list also contains all of its span, making the span the smallest subspace containing it. For balanced commands, \(S\) is the span of the single vector \((1,-1)^T\).

Bases give coordinates and count freedom (L3 00:53)

A list \(q_1,\dots,q_r\) is linearly independent if \(\sum_j c_jq_j=0\) implies every coefficient \(c_j=0\). A basis of a space is a linearly independent list spanning that space. Given a basis, expressing a vector as a combination is possible by spanning and unique by independence: subtract two expressions for the same vector and use the zero-combination condition.

For the input space use the balanced direction \(q_1=(1,-1)^T\) and common direction \(q_2=(1,1)^T\). They are independent because the two component equations for a zero combination are \(c_1+c_2=0\) and \(-c_1+c_2=0\). They span because every coordinate pair has coefficients

\[c_1=(u-v)/2,\qquad c_2=(u+v)/2.\]

The command \((3,1)^T\) therefore has new coordinate column \((1,2)^T\). Those numbers describe one physical command because the ordered basis is part of the representation.

The dimension of a space admitting a finite basis is its basis length. The definition needs a proof of invariance. If \(p_1,\ldots,p_m\) span a space and \(q_1,\ldots,q_r\) are independent, replace spanning vectors one at a time by members of the independent list. At step \(j\), express \(q_j\) in the current spanning list containing \(q_1,\ldots,q_{j-1}\). Independence forces a nonzero coefficient on some still-unreplaced \(p_k\). Solve for that \(p_k\) to preserve the span after replacement. Each step consumes one original position, so \(r\leq m\). Applying this argument with two bases in both orders makes their lengths equal. For \(S\) the basis length is one, which is the number of free scalar settings compatible with balance.

A linear map is fixed by its action on a basis (L4 01:01)

Let \(V\) and \(W\) be vector spaces over the same field. A map \(F:V\to W\) is linear if \(F(\alpha x+\beta y)=\alpha F(x)+\beta F(y)\) for all vectors \(x,y\) and scalars \(\alpha,\beta\). Thus, for \(x=\sum_j c_jq_j\), linearity forces \(F(x)=\sum_j c_jF(q_j)\). Conversely, choose any outputs for the basis members and define the image of every input by this formula. Unique input coordinates guarantee that the definition gives a single result, and componentwise combination of coordinates proves linearity.

Choose an ordered basis for each space. The matrix of \(F\) places the coordinates of \(F(q_j)\) in its \(j\)th column. This rule comes directly from the preceding expansion. For the device, the new input basis combines commands using the columns of \(P=(q_1\ q_2)\). Keep standard coordinates for the output. Then the new matrix is

\[AP=\begin{pmatrix}0&2\\2&0\end{pmatrix}.\]

Its first column is a pure contrast and its second is a pure sum. Multiplying it by \((1,2)^T\) still gives \((4,2)^T\). More generally, if \(Q\) is an invertible output basis matrix, the new matrix is \(Q^{-1}AP\) because we encode the output \(APc\) as \(Q^{-1}APc\). For an operator from a space to itself, using the same basis change \(Q=P\) gives the similar matrix \(P^{-1}AP\). Chapter 9 studies which properties survive that coordinate change.

The linearity assumption is a practical boundary. A fixed sensor bias \(b\) would give \(x\mapsto Ax+b\) and send zero to \(b\). A linear map always sends zero to zero, since setting both scalars to zero in its defining property forces this. Subtract a known bias before applying the linear model. Unknown bias needs either a reference observation or an expanded model.

Exercises with solutions

Composition order

Problem. Use \(x=(0,1)^T\) and the same \(A\) and \(B\) to find both products applied to \(x\).

Solution. First \(Ax=(1,-1)^T\), so \(BAx=(2,-1)^T\). In reverse order \(Bx=x\), so \(ABx=(1,-1)^T\). The two paths disagree because the first doubles a nonzero measurement, while the second doubles a zero input.

Span and dimension

Problem. Determine the dimension of the subspace of commands in \(\mathbb R^3\) satisfying \(x_1+x_2+x_3=0\).

Solution. The third coordinate is \(-x_1-x_2\), so \((1,0,-1)^T\) and \((0,1,-1)^T\) span the subspace. In a zero combination the first and second coordinates independently force the two coefficients to zero. The list is a basis and the dimension is two.

A map specified on nonstandard inputs

Problem. A linear map \(G:\mathbb R^2\to\mathbb R\) assigns \(G(q_1)=4\) and \(G(q_2)=6\). Find \(G(3,1)\) and write the standard-coordinate row of \(G\).

Solution. The command has coordinates \((1,2)^T\) in \((q_1,q_2)\), so its image is \(4+2\cdot6=16\). For general input \((u,v)^T\) the image is \(4(u-v)/2+6(u+v)/2=5u+v\). Its row is \((5,1)\), which gives the same result.

What a trace can certify

Problem. Show that two coordinate matrices related by \(A'=P^{-1}AP\) have equal traces.

Solution. Apply the cyclic trace identity to \((P^{-1}A)P\). The reversed product is \(P(P^{-1}A)=A\). The identity uses only compatible dimensions, invertibility of \(P\), and cyclic interchange of the paired factors. It puts no restriction on equality of the individual diagonal entries.
