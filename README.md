# Matrix Theory lecture notes

This independent study edition follows the 80 recordings in the NPTEL Matrix
Theory playlist. It develops the course through proofs, original worked
examples, exercises with solutions, and reproducible Python laboratories.

- [Read the notes](https://az9713.github.io/nptel-matrix-theory-notes/)
- [Lecture map](source-map.html)
- [Study guide](study-guide.html)
- [Laboratories](laboratory.html)
- [Production and evidence](WORKFLOW.md)

Run `python -m pip install -r requirements.txt` and `python tools/build.py`
to rebuild the reader. Open `index.html` or serve the directory using
`python -m http.server 8000`. Run `python tools/check.py` to verify the
rebuild, local links, lecture map, and all numerical laboratories.
